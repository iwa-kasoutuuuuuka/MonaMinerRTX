## 🌟 主な特徴 (v2.1.1)

1. **🏠 2階層ナビゲーションGUI (かんたん採掘 ＆ 詳細設定・高度なツール)**:
   - 認知的過負荷を解消し、普段使いに必要な「受取アドレス入力」「デバイス・モード選択」「採掘開始」を1画面に集約。
   - リアルタイム・テレメトリーバー（ハッシュレート・電力・電気代・効率・温度/ファン・シェア数）をタブ外の最上部固定配置とし、どの設定画面を開いていても常時監視可能。
   - 採掘開始ボタン上に「現在の接続先サマリー（プール名 / ワーカー名）」を動的表示し、迷わず3秒でマイニング開始。

2. **⚡ 独自内蔵 OpenCL マイナーエンジン (外部バイナリ完全不要 & 高度JIT最適化)**:
   - Windows標準の `OpenCL.dll` と `ctypes` 経由で直接バインドし、GPU内部で Lyra2REv2 カーネルを実行時JITコンパイル。
   - **本物の Lyra2REv2 実装 (v2.1.1)**: 7段すべて（Blake256 / Keccak256 / CubeHash256 / Lyra2 4x4 / Skein-512→256 / CubeHash256 / BMW256）をリファレンス実装とビット単位で照合。Monacoin Core の regtest ノードが採掘したブロックの Nonce とも一致します（`tests/test_lyra2v2_kernel.py`）。
   - **実測ハッシュレート**: RTX 5080 で約 **65〜73 MH/s**（単一GPU・バッチ約100万スレッド）。現状のカーネルは正しさを優先した素直な実装で（Lyra2 行列は 1スレッドあたり約1.5KBのプライベート配列）、最適化の余地があります。
   - **コンパイラ最適化フラグ**: `-cl-mad-enable -cl-no-signed-zeros -cl-fast-relaxed-math`、ローカルワークグループサイズ 128。
   - **PCIe転送の極小化 (ヘッダーキャッシュ)**: 不変ヘッダーの再転送を撤廃し、適応型ディスパッチ制御（~100ms）で無駄掘り（Stale Shares）を抑制。
   - **Multi-GPU**: 全GPUに同時にカーネルを投入し、共有ノンスカーソルで探索範囲の重複を排除。ノンス空間（2³²）を使い切ると extranonce2（プール）／ブロックテンプレート（ソロ）を更新します。

3. **🤖 スマート・アイドル自動採掘 (PC離席時のみ自動スタート)**:
   - Windows API (`GetLastInputInfo`) によりユーザーのキーボード・マウス操作をミリ秒単位で監視。
   - 作業中やゲーム中は自動停止（または待機）、指定時間（例: 5分）放置で自動的にフル採掘を開始。普段使いのメインPCでも一切邪魔にならず、空き時間を100%モナーコインに変えます。

4. **💰 リアルタイム電気代・収益性 (W/MH) 計算機**:
   - GPU消費電力（W）と電気料金単価（円/kWh）から「1時間の電気代」「24時間の電気代」「月間コスト」を即座に試算。
   - 現在のハッシュレートから推定MONA日収および電気代を差し引いた純利益をリアルタイム算出。「電気代負けしていないか」が一目で分かります。

5. **🚀 Multi-GPU（複数GPU同時並列採掘）**:
   - 搭載されているすべてのGPU（NVIDIA RTX / AMD Radeonの混載にも対応）を自動検出し、選択したGPU群でNonce空間を重複なく分割並列探索。リグや複数GPU搭載PCの能力を余すところなく引き出します。

6. **🌐 スマホ対応 Web監視ダッシュボード & Discord通知**:
   - 外部ライブラリ不要の超軽量HTTPサーバーを内蔵（デフォルトポート: `8888`）。同一LAN内のスマートフォンや別PCのブラウザから、リアルタイムのハッシュレート、温度、ファン、電気代、最新ログを監視し、遠隔で開始/停止が可能。
   - Discord Webhook URL を登録すれば、マイニング開始/停止やシェア承認を自動でDiscordチャンネルへ通知。

7. **🔧 GPUハードウェア直接制御 (NVML / Power Limit & Fan)**:
   - MSI Afterburner を介さず、アプリ内から直接 NVIDIA GPU の電力上限（Power Limit: Watts）およびファン回転数（%）を安全に制御。パーツの長寿命化と静音化を両立。

8. **全世代NVIDIA & AMD Radeon GPU & CPUスペック自動検知エンジン**:
   - `NVML (NVIDIA Management Library)` および Windows WMI/CIM システム問い合わせにより、NVIDIA GeForce（RTX 5090〜GTX 1050Ti）および **AMD Radeon（RX 7900 XTX〜RX 470、Vegaシリーズ）** の型番、アーキテクチャ（Blackwell / Ada / Ampere / Turing / Pascal / RDNA 3 / RDNA 2 / RDNA 1 / Vega / Polaris）、VRAM、BIOS定格TDP、およびCPU物理/論理スレッド数をリアルタイム検出。
   - 搭載GPUのベンダー（NVIDIA / AMD）とアーキテクチャ特性に応じた最適な動作プロファイルを自動提案します。

9. **3つの最適化動作プロファイル (実機GPU & CPU 自動連動)**:
   - 🍃 **電力効率モード (Eco / Sweet Spot - 推奨)**:
     - GPU: 実機BIOSが許容する最小電力制限（例: 5080なら250W、4070なら140W、3060なら120W等）に自動設定、Intensity: 20〜21。
     - CPU: 物理コア数（例: 16スレッド）を割り当て、SMT（同時マルチスレッディング）のキャッシュ競合を回避。
     - GPUのキャッシュ効率とCPU物理コアの専有により、発熱と電気代を大幅削減しながら最高峰のワットパフォーマンスを実現。
   - ⚡ **最大計算力モード (Max Hashrate)**:
     - GPU: 定格最大TDP（例: 5080なら360W、4070なら220W等）フルパワー、Intensity: 22〜24。
     - CPU: OS/GPU用に2コアを残した最大スレッド数を投入。
     - GPUとCPUの全能力を解き放つ極限ハッシュレート構成。
   - ☕ **ながらマイニングモード (Quiet / Daily)**:
     - GPU負荷を30〜40%に抑え（ノートPCでは自動推奨）、CPUも25%（低スレッド）に制限。
     - ファンの静音を維持し、日常のPC作業（Web閲覧・動画視聴・ゲーム等）を一切妨げずに裏で静かにマイニング。

10. **🏊 プールマイニング & 🏠 ソロマイニング 両対応**:
    - **プールマイニング (Stratum)**: 国内代表プール（VIPPOOL:8888）へ接続し、安定して少額ずつの報酬を獲得。
    - **ソロマイニング (Monacoin Core RPC)**: ローカルの Monacoin Core (`127.0.0.1:9402`) と直接連携。ブロック発見時に **3.125 MONA + 取引手数料の全額（100%）** を独占獲得。

11. **💻 採掘デバイス選択 (GPU / CPU / ハイブリッド)**:
    - ⚡ **GPU のみ**: 内蔵 OpenCL エンジンで採掘します（RTX 5080 で約 65〜73 MH/s）。
    - 🧠 **CPU のみ**: 内蔵のネイティブ CPU エンジン（`app/miner/native/lyra2re2_cpu.dll`）で、指定スレッド数だけ並列に採掘します。実測は 1 スレッド約 0.15〜0.25 MH/s 程度です。
    - 🚀 **ハイブリッド (GPU + CPU)**: GPU と CPU が同じ仕事（ヘッダー）を重複なく分担して同時に採掘します（CPU の寄与は GPU の数%です）。
    - スレッド数スライダー & プリセットボタンで CPU スレッド数を調整できます。
    - **予想ハッシュレートは実測ベースです**: 「⚙️ 詳細設定 → 🔧 ハードウェア制御」の「📊 ベンチマーク実行」（約10秒）で GPU/CPU の実際の速度を計測し、結果を保存して各プロファイルの「予想」に反映します（未測定のときは「未測定」と表示。省電力/静音は電力比による目安）。

12. **安全設計とデュアル制御（管理者権限対応）**:
    - **一般ユーザー実行時**: 安全のため、Intensity（スレッド並列数）の調整でGPU負荷を制御。
    - **管理者として実行時**: NVML経由でGPUハードウェアの Power Limit（ワット数）を直接低減し、電圧降下による真の省電力化を適用。

13. **モナコイン専用設計 & ハイブリッド診断**:
    - レガシー（`M...`）および SegWit（`mona1...`）アドレスのリアルタイム正規表現バリデーション。
    - 内蔵シミュレータにより、外部マイナー未導入でもUI・負荷・ソロブロック発見の動作テストが可能。

### 【通常利用】「🏠 かんたん採掘」タブでの操作 (3ステップ)

1. **モナコイン受取アドレスの入力**:
   - 画面最上部の **「🪙 モナコイン受取アドレス (Coinbase Wallet)」** 欄に、ご自身のモナコインアドレスを入力します。
     - レガシーアドレス（`M...` から始まる33〜34文字）
     - SegWitアドレス（`mona1...` から始まる42文字前後）
   - 正しいアドレスを入力すると、右側に緑色のバッジ（`✓ 有効なアドレス`）が表示されます。

2. **採掘デバイス & 動作プロファイルの確認**:
   - **採掘デバイス**: `[⚡ GPU]` / `[🧠 CPU]` / `[🚀 ハイブリッド]` を選択（初期状態で最適な構成が自動選択されています）。
   - **動作プロファイル**:
     - `[🍃 電力効率モード]`（推奨）: 発熱と電気代を大幅カットしながら最高効率を維持。
     - `[⚡ 最大計算力モード]`: ハッシュレート最優先。
     - `[☕ 静音モード]`: 作業・ゲーム・動画視聴の邪魔をしない超静音設定。

3. **採掘開始 (Start Mining)**:
   - ボタン上部のステータスバーで現在の接続先（例: `📍 接続先: VIPPOOL ｜ ワーカー: rtx5080_worker`）を確認し、緑色の **「🚀 採掘開始 (Start Mining)」** ボタンをクリックします。
   - 上部の常時表示メトリックバーに、リアルタイムの **ハッシュレート (MH/s)、消費電力 (W)、推定電気代 (1日/円)、電力効率 (W/MH)、GPU温度/ファン (℃/%)、承認シェア数** が即座に反映されます。
   - 下部のリアルタイムログで Stratum 通信やシェア承認状況を確認できます。停止したいときは **「⏹ 採掘停止 (Stop Mining)」** を押します。

### 【高度な設定】「⚙️ 詳細設定・高度なツール」タブでの操作

接続先の変更や各スマート機能の設定は、上部の **「⚙️ 詳細設定・高度なツール」** タブにすっきり集約されています。

* **サブタブ 1: 🏊 接続設定 (プール / ソロ)**
  1. **プールマイニング (Stratum)**: ドロップダウンから VIPPOOL や F2Pool、カスタムURLを選択し、ワーカー名・パスワードを設定します。
     - ⚠️ **VIPPOOL (`stratum1.vippool.net:8888`) 利用時の重要注意点**:
       - VIPPOOL は **Webアカウント制プール (MPOS)** です。ワーカー名欄にモナコインアドレス（`MMaQa...` 等）を直接入力すると認証が拒絶されます。
       - 利用手順:
         1. [VIPPOOL 公式サイト (vippool.net)](https://vippool.net/) で無料ユーザー登録を行います。
         2. ログイン後、「My Account」→「My Workers」でワーカーを作成します（例: ワーカー名 `worker1`、パスワード `x`）。
         3. 本ツールのワーカー名欄に **`アカウント名.ワーカー名`**（例: `user1.worker1`）、パスワード欄に設定したパスワードを入力します。
     - 💡 **アカウント登録なしでアドレス直接採掘したい場合**:
       - ユーザー登録不要でモナコインアドレスを直接指定して掘れるプール、または下記の「🏠 ソロマイニング」をご利用ください。
  2. **ソロマイニング (Monacoin Core RPC)**: Monacoin Core（公式フルノード）と直接連携して単独採掘。ブロック発見時に **3.125 MONA + 取引手数料の全額（100%）** を独占獲得します。
  3. **テスト・シミュレーションモード**: 実採掘を行わずにUIや負荷動作を安全に体験可能。
  4. **外部マイナー指定**: 既存の `ccminer` や `wildrig` などの外部バイナリを使用したい場合にパスを指定。

* **サブタブ 2: 🤖 スマート・アイドル採掘**:
  - 「離席時の自動採掘を有効化」にチェックを入れ、放置判定時間（例: 5分）を設定すると、PC不使用時のみ自動採掘されます。マウスやキーボードを操作すると0.1秒で即座に一時停止します。

* **サブタブ 3: 💰 収益性・電気代計算**:
  - お住まいの電力会社料金単価（円/kWh）やMONA参考価格を入力すると、採掘中のリアルタイム電気代、24時間/月間コスト、推定純利益が自動算出されます。

* **サブタブ 4: 🌐 遠隔監視・通知**:
  - 「内蔵Webダッシュボード」をONにして「ブラウザでダッシュボードを開く」を押すと、スマホや別PCのブラウザから遠隔監視・遠隔操作が可能です（ポート `8888`）。
  - Discord Webhook URL を登録すれば、マイニング開始/停止やエラー発生時に自動通知されます。

* **サブタブ 5: 🔧 GPUハードウェア (Multi-GPU)**:
  - 複数GPUを搭載しているPCで、採掘に使用するGPUを個別チェックボックスで並列選択可能。
  - NVIDIA GPU の電力上限（W）や目標ファン速度（%）を、Afterburner不要でアプリ内から直接適用できます。

> [!TIP]
> **テスト・診断モードについて**:
> 実採掘を行わずに動作確認したい場合は、「テスト・シミュレーションモード」のチェックボックスをONにしておけば、UIや負荷制御、Stratum通信、ソロブロック発見フローの動作を安全にテスト・体験できます。

## 🛡️ ウイルス対策ソフト（セキュリティソフト）への対応

### なぜ暗号資産マイナーは警告されるのか？ (誤検知の仕組み)
暗号資産マイニングソフトウェア（ccminer、cpuminer、および本ツール等のマイナー関連バイナリ）は、**ウイルスやマルウェアそのものではありません**。

しかし、悪意あるハッカーが他人のPCに勝手にマイニングソフトを仕込んで不正採掘する「クリプトジャッキング」が世界的に存在するため、多くのアンチウイルスソフト（Windows Defender、Norton、McAfee、ウイルスバスター等）は、**正当なツールであっても一律で `PUA:Win32/CoinMiner`（望ましくない可能性のあるアプリ）や `Riskware` として機械的に検疫・ブロックする仕様**になっています。

本ソフトウェアは安全なオープンソース技術のみで構築されていますが、スムーズにご利用いただくために以下の除外設定を推奨します。

### Windows Defender (Windows セキュリティ) での除外設定手順

1. スタートメニューから **「設定」**（歯車アイコン）を開きます。
2. **「プライバシーとセキュリティ」** → **「Windows セキュリティ」** を開きます。
3. **「ウイルスと脅威の防止」** をクリックします。
4. 「ウイルスと脅威の防止の設定」の見出しにある **「設定の管理」** をクリックします。

## 🏠 ソロマイニングの完全環境構築・開始ガイド (Regtest即座テスト ＆ Mainnet本番運用)

MonaMinerRTX は、外部マイナーバイナリ（ccminer等）を別途用意することなく、**独自内蔵GPUマイナーエンジンが直接 Monacoin Core の JSON-RPC (`getblocktemplate`) を取得し、GPUで発見したブロックを `submitblock` で自律送信する完全なネイティブ・ソロマイニング**に対応しています。

プールマイニングのようにプール運営者への手数料（1〜2%）を支払う必要がなく、ブロックを発見した際は、**ブロック報酬（3.125 MONA）＋含まれるすべての取引手数料（100%）** が直接ご自身のウォレット（Coinbase）へ即時払い込まれます。

### ⚡ ステップ A: 最短5秒でブロック採掘を体験できる「即座テスト環境 (Regtest)」

「本当に自分のGPUでブロックが掘れるのか試したい」「本番の巨大なブロックチェーン同期（約10GB）を待たずにテストしたい」という方向けに、**ワンクリックで起動できるローカル Regtest（プライベート・テストネット）環境**を用意しています。

#### 1. ワンクリック起動
- MonaMinerRTX を起動し、画面上部の「⚙️ 詳細設定」タブをクリックします。
- 「🏊 プール・ソロ接続」内の「🏠 ソロマイニング」サブタブを開きます。
- **`⚡ 即座テスト環境起動 (Regtest ノード起動)`** ボタンをクリックします（または `node/start_regtest_solo.bat` を直接ダブルクリック）。

#### 2. ノードクラスタの自動待機
- 黒いコマンドプロンプト画面が開き、内部で2台の独立した Monacoin Core ノードが自動起動・相互接続されます。
- 初期化が完了すると、コンソール画面に以下の案内が表示されます：
  ```text
  ✓ 準備完了！ getblocktemplate 正常応答 (ブロック高: #61)
  ==================================================================
    GPU ソロマイニング待機状態に入りました！
    MonaMinerRTX GUI の「ソロマイニング」タブで「採掘開始」を押すと、
    RTX 5080 等のGPUで直接ブロック採掘・即座承認を体験できます。
  ==================================================================
  ```

#### 3. アプリから接続確認
- MonaMinerRTX の「🏠 ソロマイニング」タブに戻り、**`🔍 ノード接続テスト (RPC Check)`** ボタンを押します。
- 「✓ 接続成功 [チェーン: REGTEST, ブロック高: #61, 接続ピア: 1 台, IBD中: いいえ]」というポップアップが出れば準備完了です。

#### 4. 採掘開始とブロック発見
- ダッシュボード（🏠 かんたん採掘）画面に戻り、受取アドレスに、Regtest 起動スクリプトの最後に表示された **Regtest 用アドレス（`rmona1q...`）** を入力します。
  - ⚠ メインネット用の `M...` アドレス（既定値を含む）は Regtest ノードでは無効です。その場合はログにエラーを表示して採掘を停止します。
  - Regtest ノードは高さ 60 未満のブロックを scrypt で検証します（高さ 60 以降が Lyra2REv2）。GPUエンジンは Lyra2REv2 専用なので、起動スクリプトが最初にブロック高 #61 まで自動で掘り進めてから待機状態になります。
- 画面右上の **`🚀 採掘開始 (Start Mining)`** ボタンを押します。
- **体験結果**: RTX 5080等のGPUが極低難易度（Diff 1相当）で数秒以内に有効な Nonce を発見し、Monacoin Core へ送信されます。
- ログ画面に `★ ブロック採掘・承認成功！ (ブロック高 #62, 報酬: 50.00 MONA)` と緑色で表示され、最上部テレメトリーバーの「承認シェア / ブロック」に **`1 blocks`** と即座に加算されます。

#### 5. テスト環境の終了方法
- テスト終了時は、起動した黒いコンソール画面で `Ctrl + C` を押すか、`node/stop_nodes.bat` をダブルクリックしてください。ノードが安全に停止します。

### 🌐 ステップ B: 本番メインネット (Mainnet) での完全ソロマイニング運用

世界中のモナコイン・ブロックチェーンと同期して、本物の MONA 報酬を独占獲得する実践手順です。

#### 手順 1: 最適化ノードの起動
本ツールには、マイニング用にチューニングされた設定ファイル（`node/monacoin.conf`）と起動スクリプトが同梱されています。
- `node/start_mainnet_solo.bat` をダブルクリックして起動します。
  - 同梱設定: `server=1`, `rpcuser=monacoinrpc`, `rpcpassword=rpcpassword`, `rpcport=9402`, `dbcache=4096`, `txindex=1`。
- **初回同期（Sync）について**:
  - 初回起動時は全世界のモナコイン・ブロックチェーン（ヘッダー411万件・生データ約3.1GB〜）のダウンロードおよびローカル整合性検証が行われます。
  - **同期の2段階プロセス**:
    1. **ダウンロード段階**: ネットワークから過去の全ブロックデータを受信。
    2. **検証・インデックス構築段階 (IBD)**: 受信したブロックを先頭から順にPC内部で検証（`"initialblockdownload": true`）。この間はブロック生成テンプレートの受付が待機中となります。
  - **同期進捗の確認コマンド**:
    ```powershell
    # PowerShell の場合は先頭に .\ を付けて実行します（node コマンドとの誤認を回避）
    .\node\monacoin_cli.bat getblockchaininfo
    ```
    出力中の `"initialblockdownload": false` かつ `"verificationprogress": 0.999...` になれば全同期完了です。

#### 手順 2: アプリでのRPC接続設定
1. MonaMinerRTX を起動し、「⚙️ 詳細設定」→「🏊 プール・ソロ接続」→「🏠 ソロマイニング」タブを開きます。
2. 設定値を確認します（通常はデフォルトのままでOKです）：
   - **RPC Host**: `127.0.0.1`（同じPCでノードを動かす場合）
   - **RPC Port**: `9402`
   - **RPC ユーザー名**: `monacoinrpc`
   - **RPC パスワード**: `rpcpassword`
3. **`🔍 ノード接続テスト (RPC Check)`** ボタンを押します。
   - 「✓ 接続成功 [チェーン: MAIN, ブロック高: #3,XXX,XXX, 接続ピア: 8台, IBD中: いいえ]」と表示されれば、本番ソロ採掘の準備は万全です。

#### 手順 3: 本番ソロ採掘の開始
1. 「🏠 かんたん採掘」タブに戻ります。
2. 「🪙 モナコイン受取アドレス」に、報酬を受け取りたいご自身のウォレットアドレス（`M...` または `mona1...`）を入力します。
   - ※ ソロマイニングでは、ブロック発見時のCoinbaseトランザクションにこのアドレスが直接埋め込まれます。
3. 最適化プロファイル（「🍃 電力効率モード」推奨）を選択します。
4. **`🚀 採掘開始 (Start Mining)`** ボタンを押します。
5. 独自内蔵GPUエンジンが稼働し、全世界のネットワーク最新ブロックに対する探索を開始します。

### 💡 既存の Monacoin Core (公式GUI版 / monacoin-qt.exe) を利用する場合

既に公式の Monacoin Core GUI版をPCにインストールして利用している場合、既存のウォレットをそのままソロマイニングのバックエンドとして活用できます。

### ❓ ソロマイニングに関するトラブルシューティング & FAQ

#### Q1. 「ノード接続エラー: Monacoin Core is not connected! (code: -9)」と出る
- **原因**: Monacoin Core の接続ピア数（P2Pネットワークの他ノード接続）が 0 の状態で `getblocktemplate` を呼び出すと発生する Monacoin Core 側の安全仕様です。
- **対処法**:
  - 本番メインネットの場合: ノード起動後、外部ピアと接続されるまで1〜2分お待ちください。
  - テスト環境の場合: 単体起動ではなく、同梱の `node/start_regtest_solo.bat`（またはアプリの「即座テスト環境起動」ボタン）をご利用ください。自動的に相互接続ピアが構成されます。

#### Q2. 「受取アドレスがこのノードのネットワークでは無効です」と表示される
- **原因**: 受取アドレスが空、またはノードのネットワークと合っていません（メインネット: `M...` / `mona1...`、Regtest: `rmona1...`）。
- **対処法**: メイン画面の「🪙 モナコイン受取アドレス」欄に、接続先ノードに合う有効なアドレスを入力してください。

#### Q3. ソロマイニングでブロックを発見できる確率はどのくらいですか？
- **解説**: ソロマイニングは確率論（宝くじ）の世界です。例えばネットワーク全体の総ハッシュレートが 1,000 GH/s、ご自身の RTX 5080 が約 200 MH/s の場合、シェア率は約 0.02% となります。
- モナコインは平均約90秒ごとに1ブロック生成されるため、1日に生成されるブロック数は約 960 ブロックです。
- 計算上は数日〜数週間に1回の頻度でヒットする期待値となりますが、運が良ければ数時間で発見できることもあれば、1ヶ月発見できないこともあります。
- **安定して毎日確実に報酬を得たい場合は「🏊 プールマイニング」、手数料ゼロでブロック報酬（3.125 MONA）を一気に総取りしたい場合は「🏠 ソロマイニング」** を選択してください。

#### Q4. 「Monacoin is downloading blocks... (code: -10)」と出てソロ採掘が始まらない
- **原因**: メインネットノードが過去の全ブロック（411万ブロック）のダウンロードまたは整合性検証（IBD: Initial Block Download）を完了していない状態です。
- **対処法**:
  - `.\node\monacoin_cli.bat getblockchaininfo` で `"initialblockdownload": false` になるまでバックグラウンドでノードを起動したままお待ちください。
  - **今すぐ同期待ちなしでソロ採掘を試したい場合**:
    GUI右上、または「🏠 ソロマイニング」タブ内の **「⚡ 即座テスト環境起動 (Regtest)」** ボタンをクリックしてください。同期待ちゼロ秒で今すぐRTX 5080によるブロック発見・採掘テストが可能です。

#### Q5. VIPPOOL で採掘開始すると「プール認証に失敗しました」と出る
- **原因**: ワーカー名欄にモナコインアドレス（`MMaQa...` 等）を入力しているためです。VIPPOOLはWebアカウント制（MPOS）プールの仕様上、アドレス直接指定での認証を受け付けていません。
- **対処法**:
  1. [vippool.net](https://vippool.net/) にて無料アカウント登録を行います。
  2. Web管理画面の「My Workers」でワーカー（例: `worker1`、パスワード `x`）を作成します。
  3. MonaMinerRTX のワーカー名欄に **`アカウント名.worker1`**、パスワード欄に `x` を入力して採掘を開始してください。

#### Q6. PowerShell で `node\monacoin_cli.bat` を実行すると「モジュール 'node' を読み込むことができませんでした」と怒られる
- **原因**: PowerShellの構文解釈により、先頭の `node` が Node.js コマンドやPowerShellモジュール名と誤認識されるためです。
- **対処法**:
  カレントディレクトリ相対パスとして `.\` を付けるか、`cmd /c` を介して実行してください：
  ```powershell
  .\node\monacoin_cli.bat getblockchaininfo
  # または
  cmd /c node\monacoin_cli.bat getblockchaininfo
  ```

## 📋 更新履歴 (Changelog)

### v2.1.1 (2026-09-29) - 実採掘に必要な修正 (デバッグ)
* **⚠ 重要: GPU カーネルが Lyra2REv2 になっていなかった問題を修正**:
  * 旧 `lyra2v2.cl` は 6 段のうち Blake256 の 2 ブロック目・パディング、Lyra2 の行列演算、Skein の UBI、BMW、CubeHash の初期化などが省略された簡易版で、正しいハッシュを計算していませんでした（CubeHash の 2 段目も欠落）。出力の上位ワードがほぼ定数のため、目標値を少し変えるだけで「全 Nonce が有効」か「全 Nonce が無効」に振れ、**プール／メインネットで有効なシェア・ブロックを提出することはできませんでした**。v2.1.0 の「610→1,080 MH/s (+77%)」は存在しない計算に対する数字で、無効です。
  * 7 段すべてを Monacoin Core と同一のアルゴリズムで実装し直し、リファレンス実装と照合（regtest ノードが採掘した 60 ブロックの Nonce と 109 ビット分一致）。実測は RTX 5080 で約 65〜73 MH/s です。
  * カーネルの引数は `(header, base_nonce, target_hi, target_lo, found_nonce[16], found_count)` に変更（目標値は上位 64 ビットで比較。1 回の起動で最大 16 個の Nonce を返す）。
* **ソロマイニング（ブロック組み立て）の修正**:
  * コインバースの BIP34 高さ符号化が誤っていた問題を修正（高さ 1〜16 は `OP_N`、それ以外は正しい `CScriptNum`。旧実装はメインネットの高さ約 410 万で 3 バイト必要なのに 2 バイトしか出さず、`bad-cb-height` で拒否されました）。
